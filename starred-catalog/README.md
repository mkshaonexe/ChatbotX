## 🚀 Quick Launch

You can open the website instantly in your default web browser:

```bash
# macOS
open starred-catalog/index.html
```

Or serve it locally using Python:

```bash
python3 -m http.server 3333 --directory starred-catalog
# Then visit: http://localhost:3333
```

## ✨ Website Features

1. **Ultra-Fast Real-Time Search**: Instant keyword search across repository names, owners, descriptions, and technology tags.
2. **Domain & Language Filtering**: Filter by any of the 10 categories, or slice by programming language.
3. **Flagship Top Picks**: Handpicked badge highlighting best-in-class repositories with custom rationale.
4. **Visual Insights Dashboard**:
   - Interactive Doughnut Chart: Category Distribution
   - Horizontal Bar Chart: Top Programming Languages
   - Star Impact Tier Chart: Distribution across star tiers (>100k, 50k-100k, 10k-50k, 1k-10k, <1k)
5. **Deep Architectural Inspector (Modal)**:
   - Repository header with owner avatar and direct GitHub links.
   - Deep architectural summary explaining how it works.
   - Core capabilities & highlight bullets.
   - Ideal real-world use cases.
   - Quick-start clone command with one-click copy.
6. **Data Export**: One-click download of the entire enriched catalog in structured JSON format.
