## ৪. কারিগরি সমাধান (Technical Implementation Details)

`generate_inline_player.py`-এর `prepare_text_for_speech` ফাংশনে একটি শক্তিশালী **Bengali Phonetic & Symbol Normalization Engine** যুক্ত করা হয়েছে:

```python
# 1. Decimal numbers: 2.3 or ২.৩ -> "২ দশমিক ৩" (Strictly prevents Edge TTS from saying vulgar/awkward "ফুটকি")
t = re.sub(r'([\d০-৯]+)\.([\d০-৯]+)', r'\1 দশমিক \2', t)

# 2. Time notation: 10:30 or ৯:০২ -> "১০টা ৩০ মিনিট"
t = re.sub(r'([\d০-৯]{1,2}):([\d০-৯]{2})\s*(?:মিনিট)?', r'\1টা \2 মিনিট', t)
t = re.sub(r'মিনিট\s+মিনিট', 'মিনিট', t)

# 3. Numeric ranges: 5-10 or ৫-১০ -> "৫ থেকে ১০"
t = re.sub(r'([\d০-৯]+)\s*[-–—]\s*([\d০-৯]+)', r'\1 থেকে \2', t)

# 4. Degrees Celsius & Temperature: 31°C -> "৩১ ডিগ্রি সেলসিয়াস"
t = re.sub(r'([\d০-৯]+)\s*°\s*[cC]', r'\1 ডিগ্রি সেলসিয়াস', t)
t = re.sub(r'([\d০-৯]+)\s*°', r'\1 ডিগ্রি', t)

# 5. Percentages: 48% -> "৪৮ শতাংশ"
t = re.sub(r'([\d০-৯]+)\s*%', r'\1 শতাংশ', t)

# 6. Technical Units & Durations:
# 2.3s -> "২ দশমিক ৩ সেকেন্ড", 500ms -> "৫০০ মিলি-সেকেন্ড"
t = re.sub(r'([\d০-৯]+(?:\s*দশমিক\s*[\d০-৯]+)?)\s*(?:sec|s)\b', r'\1 সেকেন্ড', t)
t = re.sub(r'([\d০-৯]+(?:\s*দশমিক\s*[\d০-৯]+)?)\s*ms\b', r'\1 মিলি-সেকেন্ড', t)
t = re.sub(r'([\d০-৯]+)\s*(?:hr|h)\b', r'\1 ঘণ্টা', t)

# 7. Fractions / Division: 7/10 -> "৭ বাই ১০"
t = re.sub(r'([\d০-৯]+)\s*/\s*([\d০-৯]+)', r'\1 বাই \2', t)

# 8. Filter any literal accidental "ফুটকি" occurrence
t = re.sub(r'ফুটকি', 'দশমিক', t)
```
